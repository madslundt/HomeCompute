# Architecture decision records

This directory records durable architecture decisions and their consequences.
Read ADRs in numeric order when reconstructing the project history; use the
status section in each record to distinguish accepted constraints from proposed
work.

The indexed list and plain-language summaries live in the
[documentation guide](../README.md#architecture-decisions).

When a decision changes, preserve the old record, mark it superseded, and add a
new numbered ADR that links back to it. Do not silently rewrite historical
rationale to match a later implementation.
