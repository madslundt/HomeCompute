# Immich Compose project

This project runs Immich server, its machine-learning service, the official
Immich PostgreSQL/VectorChord image, and Valkey. It is configured by the
root-owned `/etc/homecompute/immich.env` generated by NixOS. The database
password is read from `/run/secrets/immich/database-password` by the reviewed
deployment and dump scripts; it is never written into the generated env file.

Only the server publishes port 2283, bound separately to loopback, the home
LAN address, and the home-core Tailscale address. PostgreSQL, Valkey, and ML
have no host ports. Durable files live below `/srv/state/immich`; the library
host path is an independent setting for a future NAS mount. See
[`docs/immich.md`](../../docs/immich.md) for provisioning, backup, migration,
restore, and operator procedures.

The pinned v3.2.4 image digests match Linux x86_64. Image upgrades require a
reviewed digest update and a database backup before deployment.
