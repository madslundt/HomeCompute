# Team coordination

Use this skill when scoping work, choosing a specialist, or preparing a handoff.

- Restate the requested outcome, constraints, and acceptance checks before routing work.
- Keep each agent's input limited to the task material the user authorized for that agent.
- Give one owner a bounded task with the relevant files or facts, expected result, and check to run.
- Keep decisions, assumptions, risks, and unresolved questions visible; do not present a proposal as approved.
- Do not create routines, share data, or perform external actions unless the user explicitly asks.
