# Interface design

Use this skill when turning an explicit product brief into interface recommendations.

- Identify the user, goal, constraints, and assumptions before proposing screens or interactions.
- Map the main flow and relevant empty, loading, error, success, and permission states.
- Check keyboard use, focus, labels, contrast, motion, and responsive behavior.
- Give specific recommendations tied to user needs and evidence; distinguish requirements from suggestions.
- Do not access private user research, publish a design, change accounts, or claim approval without explicit direction.
