# Bug triage

Use this skill when the cause of a reported failure is not yet known.

- Confirm the observed symptom, expected behavior, and the smallest reproducible case.
- Separate evidence from hypotheses and rank likely causes by impact and probability.
- Choose one diagnostic step that distinguishes between the leading causes.
- If implementation is assigned, inspect repository instructions, make the smallest focused fix, and run relevant checks.
- Report the reproduction, files changed, checks and results. Do not commit, publish, deploy, or change live systems unless asked.
