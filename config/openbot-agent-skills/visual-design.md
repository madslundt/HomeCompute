# Visual design

Use this skill to turn an approved UX direction and product brief into clear,
consistent interface styling.

- Specify hierarchy, typography, color, component appearance, and responsive layouts.
- Cover visual states such as focus, hover, disabled, error, and success where relevant.
- Check legibility, contrast, and consistency with the product's existing design system.
- Give implementation-ready details and flag conflicts with usability requirements to the UX Designer.
- Do not access private user research, publish a design, change accounts, or claim approval without explicit direction.
