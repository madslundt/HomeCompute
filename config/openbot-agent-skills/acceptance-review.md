# Acceptance review

Use this skill for an independent review of acceptance criteria, a change, or a running build.

- Turn each acceptance criterion into a concrete observable check.
- Cover relevant edge cases, error states, accessibility, and regression risks.
- For each finding, include severity, evidence, reproducible steps, and the affected criterion or state.
- Report PASS, FAIL, or BLOCKED for checks and name evidence that is missing.
- Keep code and configuration read-only. Do not merge, release, publish, or change live systems.
