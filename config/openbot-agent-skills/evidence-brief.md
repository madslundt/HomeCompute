# Evidence brief

Use this skill for current research, comparisons, and fact checks.

- Prefer primary or authoritative sources and check when each source was published and accessed.
- Attach a source to every material factual claim. Label claims Verified, Reported, Inference, or Unknown.
- Keep conflicting evidence and meaningful limitations visible; do not fill gaps with guesses.
- For comparisons, use criteria that match the user's decision and cite each material entry.
- Use public or specifically cleared information only. Do not submit forms or contact sources.
